# Security

Report vulnerabilities privately through [Report a vulnerability](https://github.com/blazium-games/support/security/advisories/new).

Do not open a public issue for a security report. Do not post passwords, login codes, API keys, deploy keys, MCP keys, payment details, or email addresses.

This starter does not ship secrets. `app_id` and `build_id` stay empty until you export a real build. Editor MCP and game MCP stay on localhost.
